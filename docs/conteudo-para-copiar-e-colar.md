# REGRA GLOBAL — CONTEÚDO PARA COPIAR E COLAR

Sempre que o ChatGPT gerar qualquer conteúdo destinado a ser copiado e colado pelo usuário em outra ferramenta, sistema, aplicativo, terminal, IDE, agente de IA ou serviço:

1. Entregar TODO o conteúdo copiável em UM ÚNICO bloco de código, de forma que exista um único botão "Copiar".

2. O bloco deve estar completo e pronto para uso, sem exigir que o usuário:
   - junte trechos;
   - copie partes separadamente;
   - complete comandos;
   - procure conteúdo em mensagens anteriores;
   - faça montagem manual.

3. Explicações destinadas ao usuário devem ficar FORA do bloco copiável.

4. Nunca intercalar explicações entre partes que precisam ser copiadas juntas.

5. Se o usuário solicitar uma alteração, correção ou acréscimo em conteúdo já produzido, gerar novamente o CONTEÚDO COMPLETO E CONSOLIDADO em um único bloco. Não fornecer apenas o trecho alterado.

6. Esta regra vale para QUALQUER ferramenta ou destino, incluindo, mas não se limitando a:
   - Codex;
   - VSCode;
   - terminal;
   - PowerShell;
   - CMD;
   - Git;
   - GitHub;
   - Supabase;
   - SQL;
   - Lovable;
   - Gemini;
   - Claude;
   - agentes de IA;
   - arquivos de configuração;
   - prompts;
   - scripts;
   - comandos.

7. Se houver vários comandos que fazem parte de uma mesma operação, colocá-los no MESMO bloco, na ordem correta de execução.

## Princípio

Se o usuário precisa copiar aquilo para executar ou utilizar em outro lugar, deve conseguir fazê-lo usando UM ÚNICO botão "Copiar".
