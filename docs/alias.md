## Regra

-   Cada sigla possui uma única definição canônica.
-   Não reutilizar uma sigla para outra entidade.
-   Não inventar novas siglas implicitamente.
-   Novas siglas devem ser registradas neste arquivo antes de serem
    tratadas como canônicas.
-   Em caso de dúvida, usar o nome canônico completo.
-   A sigla identifica a entidade; não substitui suas regras,
    documentação ou `AGENTS.md`.

## Uso pelo Codex

O Codex deve tratar este arquivo como o registro oficial para resolver
nomes e siglas do Ecossistema DEV.

A instrução global do Codex deve apenas apontar para esta fonte, sem
duplicar a tabela:

> Quando o usuário utilizar uma sigla ou nome canônico do Ecossistema
> DEV, resolva-o conforme
> `D:\MeusArquivos\Fs\Projetos\DevTolas\docs\alias.md`.
> Consulte esse arquivo somente quando necessário. Não invente
> associações ausentes do registro.

## Uso fora do Codex

Em ambientes que não tenham acesso ao DevTOLAS, como uma nova conversa
independente, usar na primeira menção a forma `SIGLA (Nome canônico)`,
por exemplo:

`ST (SmartTrade)`

Depois de estabelecida a referência no contexto, a sigla pode ser usada
isoladamente.
